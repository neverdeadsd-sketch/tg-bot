# Сборка ролика без внешних сервисов

Полностью офлайновый пайплайн: ни одного платного API, всё ставится с PyPI.
Результат — `photoshop-explainer.mp4`, 1920×1080, 30 fps, ровно 4:00, с русской озвучкой,
вшитыми субтитрами и фоновой подложкой.

## Зависимости

```
pip install pillow numpy imageio-ffmpeg piper-tts onnxruntime espeakng-loader
./fetch_voice.sh          # нейросетевой голос ru-irinia-medium (63 МБ)
```

- `imageio-ffmpeg` приносит статический ffmpeg — системный не нужен.
- Озвучка — **Piper**, модель `ru-irinia-medium` (ONNX, женский голос). Работает офлайн,
  веса качаются один раз из релиза rhasspy/piper. Это единственный русский Piper-голос,
  доступный вне HuggingFace; мужских там нет.
- `espeakng-loader` нужен Piper для фонемизации (и остаётся запасным движком в `tts.py`).
- Шрифт — системный DejaVu Sans (есть кириллица).

## Файлы

| Файл | Роль |
|---|---|
| `script_data.py` | сценарий: 20 блоков, реплики, плашки, палитра |
| `tts_piper.py` | Piper: синтез реплики, транслитерация латиницы, подрезка пауз |
| `fetch_voice.sh` | загрузка весов голоса |
| `tts.py` | запасной движок: ctypes-обёртка над libespeak-ng |
| `draw_kit.py` | помощники отрисовки: easing, фигуры, текст, масштаб |
| `scenes.py` | 20 сцен — по функции на блок |
| `render.py` | цикл кадров, хром кадра, субтитры, склейка через ffmpeg |
| `mix_audio.py` | раскладка реплик по началу блоков в общую дорожку |
| `make_pad.py` | фоновая подложка (синтез синусами, numpy) |
| `timing.json` | подобранный темп речи и длительность каждого блока в кадрах |

## Порядок

```bash
python3 tune_timing.py     # синтез реплик + подбор темпа -> timing.json
python3 render.py /tmp/video_silent.mp4
python3 mix_audio.py       # -> /tmp/voice.wav
python3 make_pad.py        # -> /tmp/pad.wav
python3 mux.py             # обработка голоса, микс с подложкой, сборка mp4
```

## Как устроен тайминг

`tune_timing.py` синтезирует все 20 реплик и перебирает пары «темп речи + максимальная
пауза», от самой неспешной к более плотной, пока сумма речи плюс минимум полсекунды
паузы на блок не уложится в 240 секунд. Сначала укорачиваются паузы между фразами и
только потом трогается темп — так голос не звучит загнанным. Выбрано: темп 0.98,
паузы не длиннее 0.16 с. Остаток раскидывается по блокам пропорционально длине реплики,
длительности округляются до кадра, а расхождение добивается в последний блок —
поэтому сумма всегда ровно 7200 кадров.

Субтитры режутся по знакам препинания на куски до ~104 символов, и время между
кусками делится пропорционально их длине внутри речевой части блока.

## Что получилось

`video/photoshop-explainer.mp4` — 1920×1080, 30 fps, 04:00.00, H.264 High@4.0 + AAC, 19 МБ.
Ключевой кадр каждые 2 секунды, moov в начале файла (`+faststart`), один непрерывный
проход кодирования — сегменты параллельного рендера не склеиваются потоково.
Русская озвучка, вшитые субтитры, счётчик блоков и полоса прогресса.
