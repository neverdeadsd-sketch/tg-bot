# Оформление бота

Всё ниже настраивается в [@BotFather](https://t.me/BotFather) и меняется в любой момент
без потери данных: база, заявки и статусы не зависят от названия и аватара.

---

## 1. Имя (`/setname`)

Видно в шапке чата и в списке диалогов, до 64 символов.

```
Бриф — заявки на чат-ботов
```

## 2. Описание (`/setdescription`)

Экран, который видит новый пользователь **до** нажатия «Запустить». До 512 символов —
здесь важна первая строка, остальное часто не дочитывают.

```
Соберу заявку на разработку чат-бота за 7 коротких шагов — почти везде кнопки, писать почти ничего не нужно.

Покажу примеры работ, расскажу про цены и сроки. Перед отправкой — сводка: всё можно проверить и поправить.

Оценка бесплатная, отвечаем в течение рабочего дня.
```

## 3. Короткое описание (`/setabouttext`)

Строка в профиле бота и в результатах поиска, до 120 символов.

```
Заявки на разработку чат-ботов: 7 шагов вместо анкеты. Примеры, цены, сроки. Ответ в течение дня.
```

## 4. Аватар (`/setuserpic`)

Готовые файлы лежат в `assets/`, оба 512×512 и рассчитаны на круглую обрезку:

| Файл | Что на нём |
|---|---|
| `assets/avatar_monogram.png` | Монограмма **B** на градиенте + янтарный бейдж с галочкой |
| `assets/avatar_sheet.png` | Лист-бриф с галочкой, без буквы — подойдёт при смене названия |

Ставится так: [@BotFather](https://t.me/BotFather) → `/setuserpic` → выбрать бота → отправить файл.

Требования Telegram: квадрат, от 512×512 px, **отображается кругом** — значимая часть
картинки должна быть по центру с запасом по краям. Проверяйте, как выглядит в списке
чатов при 40 px: если детали сливаются — берите вариант проще.

## 4.1 Приветственный баннер

`assets/welcome.png` — 1280×720 с названием, подзаголовком и тремя тезисами.
Бот отправляет его первым сообщением на `/start`, следом идёт меню. Файл заливается
на серверы Telegram один раз, дальше отправляется по `file_id` — трафик не тратится.

Убрать баннер — достаточно удалить или переименовать файл: бот молча пропустит его
и пришлёт только текст.

Тот же баннер можно поставить на экран «до запуска»: BotFather → `/mybots` → ваш бот
→ **Edit Bot** → пункт с картинкой описания (Description Picture).

## 4.2 Как перерисовать графику

Вся графика генерируется скриптом `assets/make_assets.py` — без нейросетей,
поэтому текст всегда чёткий, а правки бесплатны и мгновенны.

```bash
pip install Pillow          # нужен только для генерации, боту в работе не требуется
python assets/make_assets.py
```

Что удобно менять в начале скрипта: `GRAD_FROM` и `GRAD_TO` — цвета градиента,
`ACCENT` — цвет галочки. Название на баннере и тезисы в «пилюлях» — в функции
`welcome_banner()`, буква монограммы — в `avatar_monogram()`.

## 5. Команды

**Настраивать в BotFather не нужно.** Бот сам регистрирует их при каждом запуске
(`main.py` → `setup_commands`):

- всем: `/start`, `/cancel`, `/help`;
- админам — персонально, в их личном чате: `/stats`, `/orders`, `/order`, `/export`.

Если задать команды через `/setcommands`, при следующем старте бот их перезапишет.
Правьте список в `main.py` — константы `USER_COMMANDS` и `ADMIN_COMMANDS`.

## 6. Настройки приватности

| Команда BotFather | Значение | Зачем |
|---|---|---|
| `/setjoingroups` | `Disable` | Бот рассчитан на личные чаты, в группах сценарий не имеет смысла |
| `/setprivacy` | `Enable` | Бот не читает чужие сообщения в группах — меньше вопросов у клиентов |
| `/setinline` | не включать | Инлайн-режим не используется |

## Тексты внутри бота

Всё, что бот пишет в диалоге — приветствие, шаги, «Примеры работ», «Цены и сроки»,
сообщения об ошибках — лежит в одном файле **`texts.py`**. Правится без знания Python:

| Что менять | Где в `texts.py` |
|---|---|
| Приветствие на `/start` | функция `greeting()` |
| Экран «Примеры работ» | константа `EXAMPLES` |
| Экран «Цены и сроки» | константа `PRICING` |
| Варианты ответов на шагах | списки `BOT_TYPES`, `SPHERES`, `FEATURES`, `BUDGETS`, `DEADLINES` |
| Формулировки шагов | словарь `STEP_PROMPTS` |

В списках вариантов меняйте **только подписи** (второй элемент пары). Коды
(`lead`, `b3`, `d2`) уходят в `callback_data` — если поменять их, кнопки в уже
открытых у пользователей сообщениях перестанут работать.

Разметка — HTML: `<b>жирный</b>`, `<i>курсив</i>`, `<code>моноширинный</code>`.
После правки текстов перезапустите бота: `systemctl restart tg-bot`.
