# Оплата на сайте без сервера

Тот же чекаут, что в `checkout/`, но на Cloudflare Workers: сайт лежит
статикой на GitHub Pages, а этот Worker отвечает на `hollvpn.ru/api/*`.
Отдельного сервера не нужно, платить не за что — бесплатных лимитов
Cloudflare хватает с запасом.

## Что здесь своё, а что общее

Логика работы с деньгами **не дублируется**. Worker импортирует её из
`checkout/src/`:

| Файл | Откуда |
|---|---|
| `checkout/src/yookassa.js` | создание и чтение платежа |
| `checkout/src/net.js` | проверка адреса источника вебхука |
| `checkout/src/notify.js` | сообщения в Telegram |
| `checkout/src/fulfil.js` | выдача с повторами |
| `checkout/src/config.js` | тарифы и проверки конфигурации |

Своего — только то, что зависит от среды:

| Файл | Зачем |
|---|---|
| `src/index.js` | маршруты на Fetch API вместо `node:http` |
| `src/store.js` | хранилище на D1 вместо `node:sqlite` |
| `src/config.js` | переменные из `env`, а не из `process.env` |

Так сделано намеренно: две копии кода, считающего деньги, однажды
разойдутся, и разойдутся молча.

## Установка

Всё делается в панели Cloudflare, командная строка не нужна.

### 1. База

**Workers & Pages → D1 → Create database**, имя `hollvpn-orders`.

Откройте её консоль и выполните содержимое `worker/schema.sql`
(скопируйте файл целиком и вставьте).

Скопируйте **Database ID** и впишите его в `worker/wrangler.toml`
вместо `ЗАПОЛНИТЕ-ID-БАЗЫ`. Это не секрет, его можно коммитить.

### 2. Worker

**Workers & Pages → Create → Import a repository**, репозиторий
`neverdeadsd-sketch/tg-bot`.

| Поле | Значение |
|---|---|
| Root directory | `worker` |
| Build command | *оставить пустым* |
| Deploy command | `npx wrangler deploy` |

### 3. Секреты

**Настройки Worker → Variables and Secrets.** Тип **Secret**, не Text:

| Имя | Что это |
|---|---|
| `YOOKASSA_SECRET_KEY` | кабинет ЮKassa → Интеграция → Ключи API |
| `TELEGRAM_BOT_TOKEN` | у @BotFather — если выдаёте вручную |

И как обычные переменные (Text):

| Имя | Значение |
|---|---|
| `YOOKASSA_SHOP_ID` | `139865` |
| `TELEGRAM_ADMIN_CHAT_ID` | ваш id у @userinfobot — если выдаёте вручную |
| `FULFILMENT_URL` | адрес выдачи в боте — если бот выдаёт сам |

Нужен **хотя бы один** способ сообщить об оплате: либо `FULFILMENT_URL`,
либо пара `TELEGRAM_*`. Без них Worker отвечает `503` и денег не берёт —
это сделано специально, чтобы не собрать оплаты и не оказать услугу.

### 4. Вебхук

В кабинете ЮKassa адрес для уведомлений:

```
https://hollvpn.ru/api/yookassa/webhook
```

## Проверка

```bash
curl -i https://hollvpn.ru/api/health
```

- `{"status":"ok","stranded_orders":0}` — всё в порядке.
- `503` с `stranded_orders` больше нуля — есть **оплаченные, но не
  выданные** заказы. Это не «сервис приболел», это деньги взяты, а доступ
  не выдан: смотрите базу и выдавайте руками.
- `503` с текстом про бота — не хватает настройки, оплата на сайте
  выключена, кнопка ведёт в бота.

## Тесты

```bash
cd worker && node --test
```

D1 в тестах подменяется настоящим SQLite с этой же схемой, поэтому SQL
выполняется по-настоящему. Проверяются не счастливые пути, а то, чем
в платежах ломают: подменённая сумма, повторный вебхук, чужой источник
уведомления, залив заказами и попытка принимать деньги без способа их
выдать.

## Чего Worker не делает

- **Не хранит адреса покупателей.** Ограничитель частоты держит хеш
  адреса, а не адрес: по нему нельзя восстановить, кто заходил, но можно
  понять, что это тот же посетитель. Строки живут час.
- **Не логирует секретный ключ.** Он существует только в секретах
  Cloudflare и в заголовке `Authorization`.
- **Не верит телу уведомления.** По id платежа статус перечитывается
  из API ЮKassa, и решение принимается только по ответу API.
- **Не берёт сумму от клиента.** Клиент присылает число дней; цена —
  в `checkout/src/config.js`, на стороне сервера.
