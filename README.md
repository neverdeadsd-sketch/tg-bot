# memebot — автоторговля мемкоинами на Solana

Telegram-бот, который сам ищет мемкоины, отсеивает скам, покупает через **Jupiter**
и продаёт по стоп-лоссу, тейк-профиту и трейлинг-стопу. Всё управление — из Telegram.

> ⚠️ Мемкоины — это высокий риск. Большинство токенов падают до нуля, а преимущество
> у инсайдеров и снайперов. Бот ограничивает убытки, но не гарантирует прибыль.
> Вкладывай только то, что готов потерять полностью.

## Как работает

Каждую минуту:

1. **Кандидаты.** Берёт трендовые и продвигаемые токены Solana с DexScreener.
2. **Рыночный фильтр.** Ликвидность, объём, капитализация, возраст пула (по умолчанию от 12 ч),
   сделки за час, перевес покупок, рост за час без вертикального пампа, токен не падает прямо сейчас.
3. **Проверка на скам (RugCheck).** Отозваны mint и freeze authority, ликвидность заблокирована,
   низкая оценка риска, нет критических предупреждений, нет налога на перевод, не Token-2022.
4. **Проверка «купить и сразу продать».** Две реальные котировки Jupiter: если на круге теряется
   больше 6%, токен отбрасывается. Так ловятся honeypot (купить можно, продать нельзя), скрытые
   налоги и слишком тонкая ликвидность.
5. **Покупка** на `BUY_AMOUNT_SOL` через Jupiter.

Каждые 15 секунд по каждой позиции получает **реальную цену продажи** (котировку Jupiter
на весь остаток, а не цену с графика) и решает:

| Правило | По умолчанию |
|---|---|
| Стоп-лосс | −25%: продать всё |
| Тейк-профит | +100%: продать половину, то есть вернуть вложенное |
| Трейлинг-стоп | после +30% продать всё при откате на 20% от пика |
| Время | через 24 ч продать всё |

**Защита депозита:** не больше 3 позиций одновременно, дневной лимит убытка (дальше покупки
останавливаются до следующего дня), общий лимит убытка (дальше пауза до `/resume`),
неприкосновенный резерв SOL на комиссии. Один и тот же токен повторно не покупается 24 ч.

## Почему Jupiter

Мемкоины на Solana торгуются на DEX (Raydium, Orca, Meteora, PumpSwap), а не на обычных биржах.
Jupiter — агрегатор: он сам находит лучшую цену по всем этим площадкам. Сделка идёт прямо с твоего
кошелька, без KYC и без передачи денег бирже. Binance или Bybit тут не подходят: свежих мемкоинов
там нет, а деньги пришлось бы держать на бирже.

## Подготовка (один раз, ~15 минут)

1. **Бот в Telegram.** Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. **Свой ID.** Напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число — это `ADMIN_CHAT_ID`.
   Потом открой своего нового бота и нажми **Start**, иначе он не сможет тебе писать.
3. **Отдельный кошелёк** (только для режима live). В Phantom: *Добавить аккаунт → Создать новый*,
   затем *Настройки → Управление аккаунтами → новый аккаунт → Показать приватный ключ*. Переведи на него только ту сумму,
   которой готов рискнуть (например 0.5 SOL), и **не используй этот кошелёк ни для чего другого**:
   бот считает результат сделок по изменению баланса.
4. **RPC** (желательно для live). Бесплатный ключ на [helius.dev](https://helius.dev) →
   `SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...`. Публичный RPC тоже работает, но медленнее.
5. **Jupiter API** (желательно). Бесплатный ключ на [portal.jup.ag](https://portal.jup.ag) → `JUPITER_API_KEY`.

## Запуск

### На сервере через Docker (рекомендуется: бот должен работать круглосуточно)

```bash
git clone <этот репозиторий> memebot && cd memebot
cp .env.example .env
nano .env                       # TELEGRAM_BOT_TOKEN, ADMIN_CHAT_ID, остальное по желанию
docker compose up -d --build
docker compose logs -f          # смотреть, что происходит
```

### Локально

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env
python -m memebot
```

## Сначала бумага, потом деньги

По умолчанию `TRADING_MODE=paper`: бот берёт **реальные котировки Jupiter**, но торгует
виртуальным 1 SOL. В бумажном режиме к каждой сделке добавляется комиссия и 1% проскальзывания,
чтобы результат не выглядел лучше реального.

1. Запусти в `paper` на 1–2 недели. Смотри `/status` и `/history`.
2. Если итог в минусе, меняй фильтры или не переходи на реальные деньги. Это и есть смысл бумаги.
3. Для реальных сделок: в `.env` поставь `TRADING_MODE=live`, укажи `WALLET_PRIVATE_KEY` и перезапусти
   (`docker compose up -d`). Бумажная и боевая статистика хранятся раздельно.

Если хочешь сам подтверждать каждую покупку, поставь `AUTO_BUY=false`: бот будет присылать сигнал
с кнопкой «Купить», а продавать всё равно будет сам по правилам.

## Команды в Telegram

| Команда | Что делает |
|---|---|
| `/status` | режим, баланс, результат за сегодня и всего |
| `/positions` | открытые позиции с кнопками «Продать» |
| `/history` | последние 10 закрытых сделок |
| `/scan` | что бот видит прямо сейчас и почему отбрасывает (без покупок) |
| `/buy <адрес>` | купить вручную (проверки на скам всё равно выполняются) |
| `/sell <номер>` | продать позицию |
| `/sellall` | продать всё (с подтверждением) |
| `/pause` / `/resume` | остановить или продолжить новые покупки; стопы продолжают работать |
| `/settings` | текущие лимиты и фильтры |

Бот отвечает только на сообщения с `ADMIN_CHAT_ID`.

## Безопасность

- Приватный ключ лежит только в `.env` на твоём сервере. Никому не передавай его и не коммить
  (файл `.env` уже в `.gitignore`).
- Ключ никуда не отправляется: транзакции подписываются на сервере и уходят только в указанный RPC.
  Бот подписывает только те транзакции от Jupiter, где плательщик — твой кошелёк.
- Отдельный кошелёк с небольшой суммой — главная защита: даже при полном сбое теряется только он.
- Пустые токен-аккаунты после продажи бот закрывает сам, возвращая ~0.002 SOL ренты за каждый.

## Ограничения и что проверено

- Логика (фильтры, правила выхода, лимиты, учёт баланса, подпись транзакций) покрыта тестами:
  `pip install -r requirements-dev.txt && pytest`.
- Формат запросов к DexScreener, RugCheck, Jupiter и Solana RPC написан по их документации.
  **Код ещё не запускался на живых API.** Поэтому начинай с `paper` и `/scan`: если какой-то API
  изменился, это сразу будет видно по причинам отказа в `/scan` и по логам.
- Бот не конкурирует со снайперами за первые секунды запуска: он намеренно берёт токены старше 12 часов
  с ликвидностью и объёмом. Это безопаснее, но больших иксов на ранних запусках не будет.
- Прибыль с крипты облагается налогом. Выгрузка сделок — таблица `trades` в `data/memebot.db`.
