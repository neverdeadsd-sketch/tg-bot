# HollVPN — сайт

Статический сайт для продажи HollVPN: лендинг с трёхмерным глобусом
и справочник на 30 статей. Открывается как обычные файлы, собирать нечем —
сборки нет.

```
site/
├── index.html          лендинг
├── guide.html          справочник
├── favicon.svg  robots.txt  sitemap.xml
└── assets/
    ├── css/main.css    дизайн-система, обе темы, вся раскладка лендинга
    ├── css/guide.css   раскладка справочника
    └── js/
        ├── world.js      контуры материков для глобуса
        ├── globe.js      рендер глобуса на WebGL
        ├── qr.js         генератор QR-кодов
        ├── leakcheck.js  проверка «что о вас видно»
        ├── kb-data.js    ← тексты справочника
        ├── app.js        ← настройки: бот, цены, тарифы
        └── guide.js      навигация и маршрутизация справочника
```

## Запуск

```bash
cd site
python3 -m http.server 8000
```

Открыть <http://localhost:8000>. Серверная часть не нужна — подойдёт
любой статический хостинг.

Перед публикацией:

```bash
bash scripts/check-site.sh
```

Проверяет главное — что сайт не подгружает ничего извне, — а заодно
синтаксис JS и что локальные ссылки ведут в существующие файлы.

## Публикация

Сайт выкладывается на **GitHub Pages** воркфлоу `.github/workflows/site.yml`:
push в `main` с изменениями в `site/` → проверка → публикация. На pull
request проверка тоже запускается, но публикация нет.

Что нужно сделать один раз в репозитории:

1. **Settings → Pages → Source: GitHub Actions.**
2. Когда захотите свой домен — там же **Custom domain: `hollvpn.ru`**,
   а у регистратора завести записи, которые GitHub покажет на той же
   странице (для домена без `www` это четыре A-записи).

До настройки домена сайт открывается по адресу вида
`https://neverdeadsd-sketch.github.io/tg-bot/` — все пути относительные,
поэтому во вложенном каталоге он работает так же.

### Почему сайт не стоит класть на сервер с VPN

Адреса GitHub в России временами недоступны, и первая мысль — поставить
сайт на свой сервер. Если это сервер, через который ходят клиенты, —
не стоит: продающий домен и рабочая нода разделят не только IP,
но и блокировки. Заблокируют домен — пропадёт нода, за которую платят.

Доступность лечится иначе и бесплатно: домен заводится в Cloudflare,
посетители приходят на адреса Cloudflare, а GitHub Pages остаётся
источником. Настройка — в панели Cloudflare, в коде менять нечего.

  оплаты», и это остаётся верным, что бы вы ни подключили;
- **автоплатёж** — механики автосписания не было, тексты теперь говорят

- **секция отзывов** — три вымышленных отзыва с именами и сроками подписки.
  Когда появятся настоящие, проще добавить новую секцию, чем восстанавливать
  эту: разметка была на три карточки `.quote` в сетке `.quotes`.

## Что поменять перед запуском

### 1. Бот, поддержка и цены — `assets/js/app.js`

Единственное, что осталось подставить из обязательного, — **@username бота**
(`CONFIG.bot`): в скриншотах он не виден, сейчас стоит `hollvpn_bot`.


Всё собрано в объекте `CONFIG` в начале файла:

```js
var CONFIG = {
  bot:      'hollvpn_bot',      // https://t.me/<bot>
  support:  'hollvpn_support',
  channel:  'hollvpn_status',
  checkout: '',                 // путь к чекауту; пусто = ссылка скрыта
  currency: '₽',
  plans: [ /* название, цена за месяц и за год, устройства, список фич */ ]
};
```

Ссылки на Telegram проставляются автоматически во все элементы с атрибутом
`data-tg`; метка в `data-utm` попадает в `?start=` — по ней в боте видно,
с какой кнопки пришёл человек.

Подписка одна, отличается только оплаченный срок — как в боте:

```js
subscription: {
  devices: 1,
  features: [ /* что входит */ ],
  terms: [
    { days: 30,  price: 199,  label: '1 месяц'   },
    { days: 90,  price: 499,  label: '3 месяца'  },
    { days: 180, price: 899,  label: '6 месяцев' },
    { days: 365, price: 1499, label: 'Год'       }
  ]
}
```

Цена за месяц, скидка относительно месячного тарифа и подписи на кнопках
считаются сами. Добавить или убрать срок — одна строка в `terms`.

### 1a. Названия позиций для платёжного сервиса

Формулировки должны совпадать в трёх местах: на сайте, в боте и в счёте
ЮKassa. Иначе покупатель видит в чеке одно, а в оферте другое.

| Название позиции | Цена |
|---|---|
| Доступ к сервису HollVPN, 30 дней | 199,00 ₽ |
| Доступ к сервису HollVPN, 90 дней | 499,00 ₽ |
| Доступ к сервису HollVPN, 180 дней | 899,00 ₽ |
| Доступ к сервису HollVPN, 365 дней | 1 499,00 ₽ |

Одинаково для всех позиций: количество 1 шт., **без НДС** (самозанятый
на НПД), признак предмета расчёта — услуга, признак способа расчёта —
полная предоплата. Назначение платежа: «Оплата по публичной оферте,
размещённой на hollvpn.ru».

Название взято из предмета договора в оферте («доступ к серверам сервиса
HollVPN»). Меняете тариф — правьте в трёх местах сразу:
`CONFIG.subscription.terms`, таблицу в разделе 4 оферты
(`kb-data.js` → `legal-terms`) и позиции в ЮKassa.

### 2. Локации — `assets/js/globe.js`

Массив `LOCATIONS` задаёт и светящиеся узлы на глобусе, и строки таблицы
серверов. Сейчас там две ноды:

```js
{ id: 'nl', city: 'Амстердам', country: 'Нидерланды', lat: 52.37, lon: 4.90  },
{ id: 'fi', city: 'Хельсинки', country: 'Финляндия',  lat: 60.17, lon: 24.94 }
```

Добавите третью — она сама появится и на глобусе, и в таблице, и в поиске
по ⌘K. Рядом лежит `INFLOW` — концы дуг, входящих в узлы: это не серверы
и не подписи, а только визуализация сходящегося трафика.

### 3. Тексты справочника — `assets/js/kb-data.js`
Категории и статьи лежат одним массивом. Чтобы добавить статью, допишите
объект в `articles` нужной категории:

```js
{ id: 'setup-mikrotik',            // становится якорем guide.html#setup-mikrotik
  title: 'Роутеры MikroTik',
  summary: 'Одна строка для поиска и подзаголовка.',
  body: `<p>HTML статьи…</p>` }
```

Разметка внутри `body`: `<ol class="kb-steps">` — нумерованные шаги,
`<ul class="kb-list">` — список, `<div class="callout">` и
`<div class="callout--warn">` — врезки, `<pre data-copy><code>` — блок команд
с кнопкой копирования, `<div class="kb-table-wrap"><table class="kb-table">` —
таблица. Навигация, поиск, ⌘K, «назад/дальше» и `sitemap.xml` подхватят
статью сами.

### 4. Домен

Домен `hollvpn.ru` прописан в `robots.txt`, `sitemap.xml`, `canonical`
и `og:url` обеих страниц. Меняется — правьте в этих четырёх местах.

Статьи справочника — хэши одной страницы, поэтому в `sitemap.xml` их нет:
поисковики отбрасывают фрагменты, и 30 записей `guide.html#…` были бы
тридцатью дублями одного URL. Если статьи нужны в выдаче по отдельности,
их придётся раскладывать в отдельные HTML-файлы.

### 5. Юридические документы

Оферта и политика конфиденциальности написаны под **самозанятого** (НПД)
по фактическим условиям сервиса: цены и сроки из бота, одна подписка на одно
устройство, возврат пропорционально неиспользованным дням (ст. 32 ЗоЗПП),
перечень собираемых и не собираемых данных.

Реквизиты в текст не вписаны — они берутся из `CONFIG.legal` в `app.js`:

```js
legal: {
  name:    '',   // ФИО полностью
  inn:     '',   // ИНН самозанятого
  email:   '',   // адрес для обращений
  updated: '9 сентября 2026 г.'
}
```

ФИО и ИНН заполнены. Остался **email для обращений** — пока он пуст,
предупреждение над документами не исчезнет.

Пока `name`, `inn` или `email` пусты, над каждым юридическим документом
висит предупреждение «Документ не готов к публикации», а прочерки на местах
реквизитов подсвечены. Заполните — предупреждение исчезнет само, значения
подставятся в четырнадцать мест сразу.

**Документы не проверены юристом.** Это добросовестный черновик по реальным
условиям, а не заверенный текст: перед подключением эквайринга покажите
их юристу. Отдельно проверьте раздел 7 оферты (возврат) — формула
пропорционального возврата выбрана как наиболее защищённая для потребителя,
но ваши условия могут отличаться.

## Почему нет зависимостей

Ни одного стороннего скрипта, шрифта и запроса на чужой домен — включая глобус
и QR-код, которые обычно тянут библиотеки. Причины две.

Первая практическая: `three.js` весит около 600 КБ, а глобус здесь —
12 КБ на чистом WebGL 1. Никакого CDN в критическом пути загрузки.

Вторая по существу: сайт VPN-сервиса, который на странице «что о вас видно»
подключает чужую аналитику и Google Fonts, спорит сам с собой. Шрифты
системные, проверка приватности целиком выполняется в браузере, аналитики
и cookie-баннера нет.

## Как это устроено

**Глобус** (`globe.js`) — сфера, точечная карта суши, светящиеся узлы и дуги
больших кругов с бегущими пакетами. Непрозрачная сфера рисуется первой и
работает маской глубины: дальняя сторона точек и дальняя половина каждой дуги
отсекаются буфером глубины, без сортировки на нашей стороне. Контуры материков
(`world.js`) заданы кольцами координат, точка считается сушей по алгоритму
пересечения луча; внутренние моря вычитаются отдельным списком.

Глобус останавливается, когда уходит из зоны видимости или вкладка становится
фоновой, и не запускается вовсе при `prefers-reduced-motion`. Если WebGL
недоступен, на его месте появляется текстовая заглушка.

**QR-код** (`qr.js`) — байтовый режим, уровень коррекции M, версии 1–6.
Проверен на совпадение матрицы с эталонной реализацией и на чтение
сканером: код со страницы декодируется обратно в исходную ссылку.

**Проверка приватности** (`leakcheck.js`) — часовой пояс, языки, экран,
видеокарта, отпечаток canvas и локальный адрес через WebRTC. Ни одного
сетевого запроса; STUN-сервер намеренно не используется, поэтому современные
браузеры отдают mDNS-имя вместо настоящего адреса — это и показывается
как хороший результат.

**Задержка до серверов** — оценка, а не замер: координаты посетителя берутся
из его часового пояса, дальше расстояние по большому кругу и скорость света
в оптоволокне. Так честно и не требует ни geo-API, ни пинга по сети;
на странице это подписано словом «оценка».

## Поведение

- **Темы.** Тёмная по умолчанию, светлая по переключателю; выбор хранится
  в `localStorage`. Глобус меняет палитру и режим смешивания вместе с темой.
- **⌘K / Ctrl+K** (и `/`) — поиск по разделам, статьям справочника
  и локациям, со стрелками и Enter.
- **`prefers-reduced-motion`** — анимации, наклон карточек и вращение
  глобуса выключаются.
- **Без JavaScript** — весь текст, таблицы и FAQ остаются на месте;
  не работают глобус, подбор тарифа и калькулятор.
- **Доступность** — переход к содержимому, видимый фокус, разметка таблиц
  через `<th scope>`, `aria-*` на палитре и переключателях.

## Иконки

Спрайт `<svg><defs><symbol>` продублирован в начале `index.html`
и `guide.html`. Это осознанно: внешний спрайт через `<use href="…svg#id">`
экономил бы 40 строк, но при промахе кэша или ошибке загрузки иконки
исчезают молча. При правке спрайта меняйте оба файла.
