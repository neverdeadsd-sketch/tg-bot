# HollVPN — сайт

Статический сайт для продажи HollVPN: лендинг с трёхмерным глобусом
и справочник на 30 статей. Открывается как обычные файлы, собирать нечем —
сборки нет.

```
site/
├── index.html          лендинг
├── guide.html          справочник
├── favicon.svg  robots.txt  sitemap.xml
└── assets/
    ├── css/main.css    дизайн-система, обе темы, вся раскладка лендинга
    ├── css/guide.css   раскладка справочника
    └── js/
        ├── world.js      контуры материков для глобуса
        ├── globe.js      рендер глобуса на WebGL
        ├── qr.js         генератор QR-кодов
        ├── leakcheck.js  проверка «что о вас видно»
        ├── kb-data.js    ← тексты справочника
        ├── app.js        ← настройки: бот, цены, тарифы
        └── guide.js      навигация и маршрутизация справочника
```

## Запуск

```bash
cd site
python3 -m http.server 8000
```

Открыть <http://localhost:8000>. Любой статический хостинг подойдёт:
Nginx, Vercel, Netlify, GitHub Pages, S3. Серверная часть не нужна.

## Что поменять перед запуском

### 1. Бот, поддержка и цены — `assets/js/app.js`

Всё собрано в объекте `CONFIG` в начале файла:

```js
var CONFIG = {
  bot:      'hollvpn_bot',      // https://t.me/<bot>
  support:  'hollvpn_support',
  channel:  'hollvpn_status',
  checkout: '/checkout',        // куда ведёт «оплатить на сайте»
  currency: '₽',
  plans: [ /* название, цена за месяц и за год, устройства, список фич */ ]
};
```

Ссылки на Telegram проставляются автоматически во все элементы с атрибутом
`data-tg`; метка в `data-utm` попадает в `?start=` — по ней в боте видно,
с какой кнопки пришёл человек.

Цены задаются двумя числами: `month` — стоимость месяца при помесячной оплате,
`year` — стоимость месяца при годовой. Скидка, годовая сумма и текст в
переключателе считаются сами. Если тарифы устроены иначе (например, по срокам
1/3/6/12 месяцев при одном наборе возможностей), структуру `plans` нужно
переделать — вёрстка карточек к этому готова, меняется только `planCard()`.

### 2. Локации и загрузка — `assets/js/globe.js`

Массив `LOCATIONS` задаёт и точки на глобусе, и строки таблицы серверов.
Поле `load` — доля от 0 до 1. Сейчас это константы; чтобы показывать
настоящую загрузку, подставляйте её из своего API перед вызовом
`HollGlobe.init()`.

### 3. Тексты справочника — `assets/js/kb-data.js`
Категории и статьи лежат одним массивом. Чтобы добавить статью, допишите
объект в `articles` нужной категории:

```js
{ id: 'setup-mikrotik',            // становится якорем guide.html#setup-mikrotik
  title: 'Роутеры MikroTik',
  summary: 'Одна строка для поиска и подзаголовка.',
  body: `<p>HTML статьи…</p>` }
```

Разметка внутри `body`: `<ol class="kb-steps">` — нумерованные шаги,
`<ul class="kb-list">` — список, `<div class="callout">` и
`<div class="callout--warn">` — врезки, `<pre data-copy><code>` — блок команд
с кнопкой копирования, `<div class="kb-table-wrap"><table class="kb-table">` —
таблица. Навигация, поиск, ⌘K, «назад/дальше» и `sitemap.xml` подхватят
статью сами.

### 4. Домен

Заменить `hollvpn.com` в `robots.txt`, `sitemap.xml` и в `<link rel="canonical">`
в `index.html`.

### 5. Юридические документы

Три статьи в категории «Документы» (`legal-terms`, `legal-privacy`,
`legal-refund`) — **шаблоны-рыба**, помеченные предупреждением прямо в тексте.
Замените их на документы, согласованные с юристом, и уберите предупреждения.

## Почему нет зависимостей

Ни одного стороннего скрипта, шрифта и запроса на чужой домен — включая глобус
и QR-код, которые обычно тянут библиотеки. Причины две.

Первая практическая: `three.js` весит около 600 КБ, а глобус здесь —
12 КБ на чистом WebGL 1. Никакого CDN в критическом пути загрузки.

Вторая по существу: сайт VPN-сервиса, который на странице «что о вас видно»
подключает чужую аналитику и Google Fonts, спорит сам с собой. Шрифты
системные, проверка приватности целиком выполняется в браузере, аналитики
и cookie-баннера нет.

## Как это устроено

**Глобус** (`globe.js`) — сфера, точечная карта суши, светящиеся узлы и дуги
больших кругов с бегущими пакетами. Непрозрачная сфера рисуется первой и
работает маской глубины: дальняя сторона точек и дальняя половина каждой дуги
отсекаются буфером глубины, без сортировки на нашей стороне. Контуры материков
(`world.js`) заданы кольцами координат, точка считается сушей по алгоритму
пересечения луча; внутренние моря вычитаются отдельным списком.

Глобус останавливается, когда уходит из зоны видимости или вкладка становится
фоновой, и не запускается вовсе при `prefers-reduced-motion`. Если WebGL
недоступен, на его месте появляется текстовая заглушка.

**QR-код** (`qr.js`) — байтовый режим, уровень коррекции M, версии 1–6.
Проверен на совпадение матрицы с эталонной реализацией и на чтение
сканером: код со страницы декодируется обратно в исходную ссылку.

**Проверка приватности** (`leakcheck.js`) — часовой пояс, языки, экран,
видеокарта, отпечаток canvas и локальный адрес через WebRTC. Ни одного
сетевого запроса; STUN-сервер намеренно не используется, поэтому современные
браузеры отдают mDNS-имя вместо настоящего адреса — это и показывается
как хороший результат.

**Задержка до серверов** — оценка, а не замер: координаты посетителя берутся
из его часового пояса, дальше расстояние по большому кругу и скорость света
в оптоволокне. Так честно и не требует ни geo-API, ни пинга по сети;
на странице это подписано словом «оценка».

## Поведение

- **Темы.** Тёмная по умолчанию, светлая по переключателю; выбор хранится
  в `localStorage`. Глобус меняет палитру и режим смешивания вместе с темой.
- **⌘K / Ctrl+K** (и `/`) — поиск по разделам, статьям справочника
  и локациям, со стрелками и Enter.
- **`prefers-reduced-motion`** — анимации, наклон карточек и вращение
  глобуса выключаются.
- **Без JavaScript** — весь текст, таблицы и FAQ остаются на месте;
  не работают глобус, подбор тарифа и калькулятор.
- **Доступность** — переход к содержимому, видимый фокус, разметка таблиц
  через `<th scope>`, `aria-*` на палитре и переключателях.

## Иконки

Спрайт `<svg><defs><symbol>` продублирован в начале `index.html`
и `guide.html`. Это осознанно: внешний спрайт через `<use href="…svg#id">`
экономил бы 40 строк, но при промахе кэша или ошибке загрузки иконки
исчезают молча. При правке спрайта меняйте оба файла.
